# Tech Club Agents · read me

Everything the club's agents make or use lives in this folder.

| Folder | What's in it |
|---|---|
| **00 Read me** | This page, the fleet (every agent's profile, playbook and rules), the weekly digests |
| **01 To approve** | Ready-to-post kits and drafts waiting for an organizer. One subfolder per item. |
| **02 Published** | Kits that went out (move the folder here after posting) |
| **03 Marketing** | Content calendar, partner sheet (companies and local businesses), outreach, dossiers |
| **04 Community** | Climb Coach rounds, follow-up messages, buddy suggestions |
| **05 Planning** | Season drafts, session ideas, the school calendar |
| **06 School** | Pedagogy and BDE: meeting briefs, follow-ups, permissions |
| **07 Games** | aivancity games: jams, rules, submissions, vote results |
| **08 Data** | Daily club snapshot, post results per platform, the Analyst's reports |
| **09 Code backup** | Copies of the agents' code while it isn't on GitHub yet |

## Your week (about 30 minutes, Sunday)
1. Read the digest in **00 Read me**.
2. Open **01 To approve**: check each kit (the "À vérifier" list at the top of its text), post it with
   Meta Business Suite, LinkedIn and TikTok, then move the folder to **02 Published**.
3. Send the email drafts waiting in Outlook.
4. After posting, paste each post's numbers (views, saves, shares, link clicks) in **08 Data / Post results**.
